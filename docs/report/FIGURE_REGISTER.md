# Figure Register
## WS-INT8 Systolic Array for Neural Network Inference

> Master register for figures considered for the college report.
> Every report figure must have a clear purpose and supporting evidence.
> Existing verification evidence is not automatically a report figure.

---

## Figure Naming Convention

Format:

FIG_<Chapter>_<Sequence>_<Short_Description>.png

Example:

FIG_03_01_PE_Architecture.png

Rules:
- Use sequential numbering within each chapter.
- Use short, descriptive names.
- Do not use "final", "final2", "new", or date-based names.
- Preserve original verification evidence separately.
- Only approved report figures receive FIG_ naming.
